# europetime.net — Europe Time Live Clock & Converter

A real-time clock and time zone converter for 37+ European countries. Track current local time across Europe with automatic DST adjustment.

## Features
- Real-time clocks for 37+ European countries
- Automatic Daylight Saving Time (DST) handling
- Time travel simulation (±24 hours)
- Dark/light theme toggle
- Mobile-friendly responsive design
- Add custom timezone support

## Tech Stack
- HTML5 / CSS3 / JavaScript
- Tailwind CSS + DaisyUI
- Cloudflare Pages (deployment)
- Schema.org structured data (WebApplication + FAQPage)

## Deployment
This site is deployed on Cloudflare Pages. Any push to the main branch triggers automatic deployment.
